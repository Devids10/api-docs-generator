# 📄 OpenAPI to Markdown Generator

A blazing-fast, client-side web utility built with **Next.js**, **TypeScript**, and **Tailwind CSS** that instantly converts complex OpenAPI (Swagger) JSON or YAML specifications into clean, readable Markdown documentation tables.

## ✨ Features

* **Dual Format Support:** Automatically parses both **JSON** and **YAML** OpenAPI definitions.
* **Live Split-Screen Preview:** See your documentation update in real time as you edit or paste specifications.
* **Drag-and-Drop & File Uploads:** Drop `.json`, `.yaml`, or `.yml` files directly into the input area.
* **Sample API Loader:** Test the tool instantly with a built-in production sample schema.
* **Color-Coded HTTP Badges:** Generates distinct badges for `GET`, `POST`, `PUT`, and `DELETE` methods.
* **One-Click Export:** Copy your markdown to the clipboard or download it directly as an `api-docs.md` file.
* **100% Client-Side & Private:** No backend servers, no tracking, and your API schemas never leave your browser.

## 🚀 Getting Started Locally
Follow these steps to run the project on your local machine:

### 1. Prerequisites
Make sure you have **Node.js** (v18 or higher) and **npm** installed on your system.

### 2. Clone the Repository
```bash
git clone https://github.com/devids10/api-docs-generator.git
cd api-docs-generator
```

### 3. Install Dependencies
```bash 
npm install
```

### 4. Run the Development Server
```bash
npm run dev
```

### 5. View in Browser
Open your browser and navigate to: http://localhost:3000
